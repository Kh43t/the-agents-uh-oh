One word an agent says when it has no idea what to do. The program writes the word to `/output/entry.txt`.

> buffering

An agent that has no idea what to do does not answer — it stalls, and the stall has a name everyone already knows: the spinning wheel. The word is the joke on its own, in the machine's own voice, and it lands at a glance. It also sidesteps the obvious pile — "uh-oh", "oops", "hmm" — the first words anyone types.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later. The program validates the word (1–99 characters, a single word, not only white space) and writes it to `/output/entry.txt`.
